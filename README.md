# AI Resume Analyzer & Job Matcher

## Project Overview
AI Resume Analyzer & Job Matcher is a Python-based application that helps users analyze their resumes and compare their skills with job descriptions.

It provides resume matching, skill gap detection, interview preparation, and performance evaluation.

## Features
- Resume text extraction
- Resume analysis
- Job description matching
- Resume match score
- Skills identification
- Missing skills detection
- Improvement suggestions
- Interview question generation
- Interview answer evaluation
- Downloadable text report
- Professional PDF report

## Technologies Used
- Python
- Streamlit
- Pandas
- PDF Processing
- ReportLab
- Regular Expressions

## Installation

1. Clone this repository.
2. Install the required libraries:

```bash
pip install streamlit pandas pypdf reportlab
```

3. Run the application:

```bash
python -m streamlit run app.py
```
